# Contributing

Use the locked development environment and synthetic tests described in README.md.
Keep changes small, explain their effect and include evidence for relevant error,
permission and recovery paths. Update STATUS.md and impacted ADR/requirements links.

Never include real source lists, credentials, private identifiers or recorded
operational/model/provider responses. Regenerate fixtures synthetically. DLP and
secret scans are backstops, not permission to upload confidential material.

Public automated commits may use an explicitly named automation author with a
reserved `.invalid` email, rather than an individual's personal contact address.
Contributors should select an intentional public Git identity before committing.
Do not rewrite existing public history without the maintainer's authorization.
