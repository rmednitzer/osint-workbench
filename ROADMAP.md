# Complete capability roadmap

Core is the first increment. The full programme remains in scope:

1. Harden acquisition, packaged migrations, evidence, leases, read APIs and recovery.
2. Token-aware chunks, embedding-space registry, real encoders, pgvector, hybrid search, rerank, caches, generation rebuild/rollback.
3. Actual local generation serving, capability probes, shared resource admission and measured CPU/GPU profiles.
4. Durable enrichment, graph assertions/aliases, context lifecycle, cited briefings and quality/abstention evaluation.
5. Vulnerability/advisory/dependency and regulatory/procedure/jurisdiction profiles.
6. Optional governed native/compatible cloud APIs, explicit data/sovereignty routing, reservations/accounting and batch reconciliation.
7. Authenticated remote MCP, scoped sessions and real client compatibility.
8. Export, publishing, retention/holds/deletion, observability, backup/restore and integrated failure/privacy acceptance.

Each capability needs independent requirements, a disposition, an implemented path and version-bound acceptance evidence. Do not treat the prototype as a correctness oracle. Preserve useful feature intent while replacing flawed coupling and implementations. See docs/adr, docs/profiles, docs/assurance and docs/testing.
